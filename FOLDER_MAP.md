# rUTIs Project Folder Structure

This document outlines the standardized folder structure for the `rUTIs` pipeline. All scripts have been refactored to adhere to this organization.

## Top-Level Directories

| Directory | Purpose |
| :--- | :--- |
| `data/` | Raw and processed input data (read-only for most scripts). |
| `results/` | Computational outputs (tables, models, intermediate files). |
| `plots/` | Visualizations generated by the pipeline. |
| `logs/` | Execution logs and debug information. |
| `R/` | Helper scripts and RMarkdown templates. |
| `docs/` | Documentation, papers, and slides. |
| `scripts/` | (Legacy) Old scripts or backups. |

## Detailed Breakdown

### `data/`
- `clinical/`: Clinical metadata (e.g., `cleaned_clinical_data.csv`).
- `assemblies/`: WGS assembly FASTA files.
- `references/`: Reference genomes (e.g., `E_coli_K12_MG1655.fasta`).

### `results/`
- `clinical/`: Processed clinical data (e.g., `status_map.csv`, `assembly_metadata.csv`).
- `vf/`: Virulence factor analysis results (`vf_hits_all.csv`, `abricate/`).
- `mlst/`: MLST typing results (`mlst_with_meta.csv`).
- `plasmids/`: PlasmidFinder results (`plasmidfinder_presence_absence.csv`).
- `wgs/`: WGS core pipeline outputs.
  - `qc/`: QC summaries.
  - `core/`: Core SNP alignment and distances.
  - `pan/`: Pangenome (Panaroo) outputs.
- `strain_compare/`: Pairwise strain comparison results.
- `models/`: GWAS and statistical model outputs (`gwas_univariable_stats.csv`).
- `reports/`: Per-participant PDF reports.

### `plots/`
- `clinical/`: Clinical summary plots.
- `vf/`: Virulence factor prevalence and heatmaps.
- `mlst/`: MLST distribution plots.
- `plasmids/`: Plasmid network and co-occurrence plots.
- `wgs/`: WGS QC and pangenome plots.
- `strain_compare/`: Pairwise comparison plots.
- `models/`: GWAS volcano and forest plots.

### `logs/`
- `debug/`: Detailed debug logs from various modules.

### `R/`
- `wgs_helpers.R`: Shared utility functions.
- `report_template.Rmd`: Template for participant reports.

## Configuration
The folder structure is defined programmatically in `00_config.R`. All scripts source this file to ensure consistent path usage.
