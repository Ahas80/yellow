# UTIGA Poster — Self-Contained Project Folder

> All data, scripts, figures, and reference documents needed for the UTIGA conference poster.

## Directory Structure

```
UTIGA/
├── README.md              ← This file
├── data/                  ← All input data files (copies from rUTIs project)
├── existing_figures/      ← Existing figures from the pipeline (for reference/reuse)
├── poster_figures/        ← NEW figures generated by poster scripts (output here)
├── scripts/               ← R scripts to generate poster figures
│   ├── poster_01_reconcile_numbers.R  — Verify abstract claims
│   ├── poster_02_flow_diagram.R       — Fig 1: CONSORT flow diagram
│   ├── poster_03_st_bar.R             — Fig 2: Top ST distribution
│   ├── poster_04_stability.R          — Fig 3: Within-host stability
│   ├── poster_05_trajectories.R       — Fig 5: Participant trajectories
│   └── poster_06_asb_vs_uti.R         — Fig 4: ASB vs UTI comparison
└── reference/             ← Abstract text, stats output, formatted abstracts
```

## How to Run

All scripts should be run **from the `UTIGA/scripts/` directory**:

```bash
cd /Users/Aamir/Desktop/rUTIs/UTIGA/scripts
Rscript poster_01_reconcile_numbers.R    # Run this FIRST
Rscript poster_02_flow_diagram.R
Rscript poster_03_st_bar.R
Rscript poster_04_stability.R
Rscript poster_05_trajectories.R
Rscript poster_06_asb_vs_uti.R
```

Output figures will be saved to `UTIGA/poster_figures/`.

## Data Files (in `data/`)

| File | Description |
|------|-------------|
| `status_map.csv` | Clinical master: participant × timepoint × infection status |
| `assembly_metadata.csv` | WGS assembly metadata |
| `mlst_with_meta.csv` | MLST calls joined with assembly metadata |
| `class_inputs_full.csv` | Linkage table: participant × timepoint → isolate_ID |
| `ST_frequencies.csv` | ST frequency distribution (all isolates) |
| `ST_core_freq.csv` | Core ST frequencies |
| `top_STs.csv` | Top STs by count |
| `ST_persistence_by_participant.csv` | Per-participant dominant ST + stability |
| `ST_consecutive_concordance.csv` | Consecutive-pair ST concordance |
| `st_risk_profile.csv` | UTI proportion by ST (Fisher's test) |
| `participant_timelines.csv` | Longitudinal timelines with Strain IDs |
| `transitions.csv` | Status/strain transitions between timepoints |
| `strain_persistence_stats.csv` | Strain persistence statistics |
| `phenotype_switch_candidates.csv` | Potential phenotype-switch events |
