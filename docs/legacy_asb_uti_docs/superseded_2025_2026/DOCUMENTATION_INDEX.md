## 📊 Data Overview

- **274 clinical episodes** from nursing home residents
- **~100 participants** (some with 6+ longitudinal timepoints)
- **382 E. coli genome assemblies** (note: 2 assemblers per sample!)
- **Phenotypes:** 42 UTI, 282 ASB, 66 Negative

---

## 🔍 Key Findings Summary

1. **Phenotype Switching:** Same bacterial strain can cause both ASB and UTI
2. **Genomic Stasis:** Switches happen WITHOUT acquiring new virulence genes
3. **Host-Driven:** Symptoms likely driven by host factors, not bacterial evolution
4. **No Lineage Effect:** ST131 not more "symptomatic" than other clones in this cohort
