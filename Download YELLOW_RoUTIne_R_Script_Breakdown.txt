
DETAILED BREAKDOWN OF R SCRIPTS IN YELLOW RoUTIne PROJECT
===========================================================

1. InitialChatGPTupdated.R
--------------------------
- Purpose: Basic metadata extraction from FASTA assemblies
- Functions:
  * Parses each .fasta file to count contigs and estimate assembly size
  * Extracts and summarizes header metadata if available
- Output: Data frame with sample ID, contig count, and other metadata

2. analyze_assemblies.R
-----------------------
- Purpose: Pairwise comparison of genome assemblies
- Functions:
  * Automates running MUMmer's dnadiff on all unique pairs
  * Parses dnadiff `.report` files
  * Extracts AvgIdentity and TotalSnpCnt
- Output: `pairwise_stats_cleaned.csv`

3. run_abricate.R
-----------------
- Purpose: Run Abricate with VFDB across all samples
- Functions:
  * Iterates through all .fasta files
  * Runs `abricate --db vfdb` and saves output
- Output: `.tsv` files per isolate with virulence gene hits

4. parse_abricate_output.R
--------------------------
- Purpose: Combine Abricate outputs into a matrix
- Functions:
  * Reads all .tsv files
  * Builds a binary gene presence/absence matrix
- Output: Single data frame of all gene hits per isolate

5. plot_virulence_upset.R
-------------------------
- Purpose: Visualize virulence gene intersections
- Functions:
  * Uses ComplexUpset and ggplot2
  * Groups samples by patient ID, timepoint, and UTI status
- Output: UpSet plots with annotated gene intersections

6. plot_avgidentity_vs_time.R
-----------------------------
- Purpose: Plot pairwise AvgIdentity for longitudinal comparisons
- Functions:
  * Highlights identity changes within-individual across timepoints
- Output: Line plots showing strain stability vs. replacement

7. annotate_nitrate_genes.R
---------------------------
- Purpose: Search for Nar, Nap, Nas nitrate reduction genes
- Functions:
  * Annotates Abricate/Prokka/ResFinder data with nitrate pathway hits
  * Labels samples as nitrate-pathway-positive or negative
- Output: Updated annotation tables

8. resistance_summary_plot.R
----------------------------
- Purpose: Visualize resistance genes from ResFinder
- Functions:
  * Plots resistance gene classes (e.g., beta-lactam, fosfomycin)
  * Compares gene presence across UTI vs. ASB isolates
- Output: Bar/heatmap plots of AMR profiles

9. correlate_virulence_clinical.R
---------------------------------
- Purpose: Statistical testing between virulence profiles and clinical outcomes
- Functions:
  * Performs logistic regression or chi-squared tests
  * Inputs: gene matrix + clinical metadata
- Output: Table of significant gene associations with UTI

10. compile_study_dashboard.R
-----------------------------
- Purpose: Generate a reporting dashboard or master table
- Functions:
  * Merges all metadata, clinical, genomic, and statistical outputs
  * Prepares combined data for manuscript figures or internal review
- Output: Cleaned dataset ready for downstream publication use
