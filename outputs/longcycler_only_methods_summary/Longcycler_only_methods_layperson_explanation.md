# Longcycler-only analysis: plain-language explanation

## One sentence

The analysis uses one consistent genome-reconstruction route for every included episode, so all downstream comparisons start from the same verified input contract.

## Thirty seconds

The analytical dataset contains **532 genome-linked episodes from 161 residents**. Every episode has one selected QC-passing Longcycler assembly. Clinical labels are assigned independently using the current operational rule: 16 episodes are UTI and 516 are Not_UTI. The larger 583-episode clinical source is shown only as attrition/QC context; it is not the analytical denominator.

## Why the numbers differ

- 532 counts episodes with selected genomes.
- 161 counts people.
- 893 counts all direct within-person genome comparisons.
- 371 counts neighbouring observations after each resident's timeline is rebuilt.
- 9 counts Not_UTI-to-UTI transitions; 5 of them are at or below 25 SNPs.
- 227 counts gene features, not samples.

## Safe conclusion

The results can describe how similar selected bacterial genomes are across sampled episodes. They cannot prove uninterrupted carriage or that a bacterial feature caused UTI. The 17 near-miss rows remain a separate audit group, and the focused casebook is complete at 9/9 linked cases.
