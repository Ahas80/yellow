# Longcycler-only methods summary for supervisor discussion

## Rationale

For the supervisor-facing primary analysis, I restricted the genomic denominator to QC-passing Longcycler assemblies only. This keeps the analysis on a single assembler, avoids mixing assembly methods in strain-resolution analyses, and makes the methods easier to defend. The existing canonical pipeline contained 556 selected genome-linked episode rows, using Longcycler preferentially with Flye fallback. The Longcycler-only analysis excludes those Flye fallback rows and does not rescue failed, missing, or non-selected Longcycler assemblies.

## Methods wording

Genome assemblies were first linked to participant and timepoint metadata, manually curated, and quality controlled. For this methods summary, the primary analysis set was restricted to selected canonical assemblies generated by Longcycler and passing assembly QC. This produced 532 genome-linked episode rows from 161 participants. Clinical episodes were classified independently using the current primary `UTI_Status` definition, separating culture-supported symptomatic UTI from `Not_UTI`. The Longcycler-only genomic set was then joined to clinical status, MLST lineage calls, virulence-factor presence/absence calls, and pairwise strain-context outputs.

Virulence-factor analyses used a binary presence/absence matrix of 227 VF genes. MLST was used as lineage context, not as definitive same-strain evidence. Same-strain persistence was defined strictly using core-genome SNP evidence, with 0-25 SNPs treated as strong same-strain support. Pairs above this threshold were not promoted to same-strain status by ST agreement alone. Longitudinal analyses rebuilt consecutive within-resident transitions after excluding Flye fallback timepoints, using the pipeline `time_order_from`/`time_order_to` values from the `cohort == "all"` transition table to preserve the established visit order.

## Longcycler-only denominator anchors

| Analysis unit | Count | Source, filter and formula |
|---|---:|---|
| Current mixed canonical rows | 556 | `vf_analysis_ready.csv`; current generated WGS/VF-ready rows before Longcycler-only restriction. |
| Longcycler genome-linked rows | 532 | `canonical_assembly_selection.csv`; `selected_canonical == TRUE`, `QC_PASS == TRUE`, `tolower(assembler) == "longcycler"`; no failed or non-selected assemblies rescued. |
| Participants represented | 161 | Distinct `Participant_id` within the 532 Longcycler-only rows. |
| Primary UTI rows | 16 | Longcycler-only keys joined to `vf_analysis_ready.csv`; `UTI_Status == "UTI"`. |
| Primary Not_UTI rows | 516 | Longcycler-only keys joined to `vf_analysis_ready.csv`; `UTI_Status == "Not_UTI"`. |
| Legacy ASB / UTI / Negative rows | 416 / 33 / 83 | Same Longcycler-only rows; `Infection_Status_legacy` retained only as descriptive context. |
| Typed MLST rows | 514 | Longcycler-only keys joined to `mlst_provider_preferred.csv`; non-missing/non-empty `ST`. |
| Distinct STs | 80 | Distinct non-missing `ST` among the 514 typed Longcycler-only rows. |
| VF gene columns | 227 | `vf_analysis_ready.csv`; binary VF gene columns from `fyuA` through `sigA`. |
| Consecutive within-resident transitions | 371 | Longcycler-only rows ordered by the pipeline time-order lookup from `vf_longitudinal_transitions.csv` with `cohort == "all"`; formula `sum(n_timepoints_per_participant - 1)`. |
| Transition participants | 139 | Participants with at least two retained Longcycler observations after the same time-order rebuild. |
| Strict same-strain transitions | 116 | Rebuilt Longcycler-only adjacent pairs joined to `pairwise_metrics.csv` by unordered participant/timepoint endpoints; `TotalSNPs <= 25` / `snp_strain_context == "Strong same strain"`. |
| Not_UTI -> UTI transitions | 9 | Rebuilt Longcycler-only adjacent pairs; `status_from == "Not_UTI"` and `status_to == "UTI"` using current primary status. |
| Not_UTI -> UTI strict same-strain transitions | 7 | Subset of the 9 Not_UTI -> UTI transitions with `TotalSNPs <= 25` / strict same-strain label. |

Important transition note: simply filtering the existing mixed transition table to Longcycler endpoints gives a smaller transition count because it cannot create new Longcycler-to-Longcycler adjacency after a Flye fallback timepoint is removed. The defensible Longcycler-only denominator is therefore rebuilt from the retained Longcycler rows using the pipeline time-order fields, then joined back to SNP pairwise metrics.

## Interpretation boundary

This Longcycler-only framing is a defensibility choice, not a claim that Flye assemblies are unusable. It prioritises a single-assembler denominator for strain, VF, MLST, and longitudinal summaries. The excluded Flye fallback rows are not used for the supervisor-facing primary method. Antibiotic, demographic, host-factor, and wgMLST-allele claims are not recalculated from proxy variables in this summary.
